## 复现

1. 按根目录 `readme.md` 初始化数据库、配置 `backend/.env.local`。
2. 在后端加载环境变量后执行 `mvn verify`；在三个前端分别执行 `npm ci`、`npm run build`。
3. 启动后端与三个前端，在 `tests` 执行 `npm ci`、`npx playwright install chromium`、`npm test`。

浏览器脚本使用初始的 5 个后台展览、3 个公开展览和 4 件作品作为基线；不要与手工修改初始数据的操作同时运行。成功运行会清理其临时记录；异常中断时会输出临时 ID，以便手动清理。

## 验证边界

未验证真实手机硬件、Windows、Safari、公网部署和多人并发编辑。503 恢复测试是浏览器网络拦截模拟，不是拔网线或停止 MySQL 的硬件故障实验。移动端为独立 H5 工程，不是原生 App。截图与结果仅支持本次展览管理与浏览模块，不代表整个原型的所有模块已经实现。
