## 已实现范围

延续前一次作业的 Web 首页，数据路径为：Vue → Vite `/api` 代理 → Spring Boot `GET /api/home` → JDBC → MySQL。

展览卡片和精选作品已改为数据库驱动；主视觉、征集说明、页脚沿用原设计。演示数据库有 4 个展览、5 件作品，公开接口返回 3 个公开展览、4 件已发布精选作品；未公开展览和隐藏作品为隔离检查用的虚构记录。

`database/schema.sql` 沿用既有完整 19 表设计，已导入 MySQL 8.4.11。本次直接查询 8 张表，另 2 张用户、类别表是外键支撑，均提供截图；其他业务表保留结构，未实现对应写入流程。

## 运行与验证

按 `springboot-backend/README.md` 配置数据库、账号和环境变量，执行 `mvn verify`、`mvn spring-boot:run`；再在 `vue-web` 内执行 `npm install`、`npm run dev`，打开 `http://127.0.0.1:4173/`。

已完成 Maven 构建与 1 项真实数据库接口集成测试、Vue 生产构建、数据库内容修改的接口同步检查、隐藏记录隔离、MySQL 日期和外键约束、只读账号权限，以及后端断开后的页面错误提示与重试恢复。

数据库截图来自真实 `INFORMATION_SCHEMA.COLUMNS` 与 `SHOW CREATE TABLE` 导出的浏览器报告，非 Navicat 等客户端截图。展示数据均为课程示例，素材沿用项目原有设计。源码包不含实际密码、`node_modules` 或构建缓存。
